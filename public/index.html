StreamX API

Movie & TV metadata, full artwork sets and episode stills. Self-hosted on Cloudflare Pages, edge-cached.

No API key required

Status: /health · Docs: README

Discovery

  • GET /catalog/movie/top?genre=Action&skip=0Top movies
  • GET /catalog/series/top?genre=DramaTop series
  • GET /search?q=dune&type=movieSearch (Cinemeta)
  • GET /imdb/search?q=duneIMDb search + posters + stars

Details

  • GET /meta/movie/tt0133093Movie: images, facts, Wikipedia plot
  • GET /meta/series/tt0944947Series: episodes, seasons, stills

Images

  • GET /images/movie/tt0133093Full artwork set (poster/backdrop/logo × 4 sizes)
  • GET /img/poster/medium/tt0133093/imgPoster
  • GET /img/background/large/tt0133093/imgBackdrop
  • GET /img/logo/original/tt0133093/imgLogo
  • GET /img/still/tt0944947/1/1/w780Episode still

Data sources

  • CinemetaTitles, cast, ratings, episodes
  • MetaHubPosters, backdrops, logos, episode stills
  • Wikidata & WikipediaBudget, box office, companies, external IDs, plot
  • IMDbSearch suggestions with posters and top cast
