StreamX API

Self-hosted movie & TV metadata and poster API. Backed by TMDB, edge-cached on Cloudflare.

Status: /health

Discovery

  • GET /trending?type=movie|tv|all&window=day|weekTrending titles
  • GET /search?q=matrix&type=multiSearch
  • GET /discover?type=movie&with_genres=28&sort_by=popularity.descBrowse / filter
  • GET /genres?type=movie|tvGenre list
  • GET /configurationImage base config

Details

  • GET /movie/:id?append=credits,videos,imagesMovie details
  • GET /tv/:id?append=credits,videos,imagesTV details
  • GET /tv/:id/season/:nSeason + episodes
  • GET /person/:idPerson + credits
  • GET /collection/:idCollection

Raw & images

  • GET /v3/:any-tmdb-pathFull TMDB passthrough
  • GET /img/:size/:filePoster / backdrop proxy, e.g. /img/w500/abc.jpg
